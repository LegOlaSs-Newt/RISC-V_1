# r04 设计与接口说明

r04以三级顺序处理器为基础，用有效位区分真实指令和气泡，EX统一处理提交、访存完成及精确异常。除法、存储等待和调试排空带归属信息，避免重复提交。预测使用128项带标签BTB、两位方向计数器及8项RAS。

## 存储与提前查询

I/D Cache各2 KiB、两路、32组、32字节行；tag为地址[31:10]，index为[9:5]，行内字偏移为[4:2]。复位清有效位，不逐字复位阵列。D写直达、不写分配，后端完成后才确认。

同步DRM读跨时钟边沿返回。提前查询在译码阶段只读地准备结果，执行阶段核对完整地址、归属和有效性后采用；取消、不匹配、失效时回到普通路径。store与MMIO不推测执行，Cache仍为阻塞式。

后端以一次整行命令传输8个32位拍，事务归属保持到末拍，支持反压和错误。它是片内DRM事务接口，不是AXI或DDR控制器。CPU修改程序后通过FENCE.I维护取指可见性。

## 地址映射

| 基址 / 范围 | 对象 |
|---|---|
| 0x00000000–0x00003FFF | 16 KiB程序区 |
| 0x10000000–0x10003FFF | 16 KiB数据RAM |
| 0x20000000 | Timer / 软件中断 |
| 0x30000000 | UART |
| 0x40000000 | GPIO模式控制 |
| 0x40000004 | GPIO数据 |
| 0x50000000 | SPI |
| 0x60000000 | 只读统计窗口 |

MMIO按实现中的精确白名单、宽度和对齐检查，并不表示整个高位地址段都合法。偏移见RTL和板级sw/include。

## GPIO和LED

每两位设置一个GPIO：00高阻、01输出、10输入。向0x40000000写5（二进制0101），将GPIO0/1设为输出。向0x40000004写1、2、3，分别对应LED3亮/LED4灭、LED3灭/LED4亮、两灯亮。

默认Demo每250 ms切换1/2；CoreMark初始化写1，成功结束写3、失败写2，因此LED3/4保持状态。LED1是硬件心跳，LED2是下载模式。更换BIN让同一CPU执行不同指令，通过现有GPIO寄存器改变电平，不改变电路结构。

## 板级边界

支持机器态Direct/Vectored入口和MRET，已接受访存按协议排空，故障指令禁止相应副作用。没有MMU和U/S态。UART下载在包CRC通过后开始写入，整包写完才ACK；独占访问切换协调排空、缓存和预测状态。

约束适配MES50HP，GPIO0–15接J16。其他板卡应核对实际引脚和电平。FPGA SRAM配置、软件下载与CPU软件JTAG职责不同；当前未启用板级CPU软件JTAG引脚。
